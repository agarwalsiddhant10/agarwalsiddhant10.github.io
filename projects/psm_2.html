One-line summary. Proto Successor Measure (PSM) provides a policy-independent basis for occupancy behavior in an MDP, enabling zero-shot adaptation to new reward functions by solving only for basis coefficients at test time.

1. Motivation and Intuition

A core goal in reinforcement learning is behavior reuse: after reward-free exploration, the agent should solve many downstream tasks without additional environment interactions. Traditional approaches often tie representation quality to a specific reward family or policy class. PSM asks a more structural question: Can we represent all possible long-horizon behaviors using a compact, reward-agnostic basis?

The key intuition is geometric: each policy induces an occupancy/visitation object. The set of feasible occupancies forms a constrained set in a high-dimensional space. PSM characterizes this set through policy-independent basis elements, so downstream control can be reframed as selecting coefficients in that basis.

2. Formal Setup

Consider a discounted MDP $\mathcal{M}=(\mathcal{S},\mathcal{A},P,\gamma)$ with $\gamma\in(0,1)$. For a policy $\pi$, define the discounted occupancy measure:

$$d^{\pi}_{\gamma}(s,a) = (1-\gamma)\sum_{t=0}^{\infty}\gamma^t\Pr_{\pi}(s_t=s,a_t=a).$$

For reward $r(s,a)$, the normalized control objective is:

$$J_r(\pi)=\mathbb{E}_{(s,a)\sim d^{\pi}_{\gamma}}[r(s,a)] = \langle r, d^{\pi}_{\gamma} \rangle.$$

Thus, control over rewards reduces to selecting the right occupancy $d^{\pi}_{\gamma}$ from the feasible occupancy set.

Proto Successor Measure Parameterization

PSM introduces a policy-independent affine parameterization of occupancies:

$$d^{\pi}_{\gamma} \approx d_0 + \sum_{k=1}^{K} w_k(\pi)\,\phi_k,$$

where $d_0$ is an offset occupancy, $\{\phi_k\}_{k=1}^{K}$ are proto basis elements (learned from reward-free data), and $w(\pi)\in\mathbb{R}^K$ are policy-dependent coefficients.

3. Main Theoretical Statements

Theorem 1 (Behavior-space representation, informal). Under the paper’s assumptions, every feasible discounted occupancy can be expressed within an affine span induced by policy-independent proto measures. Equivalently, the policy-induced behavior space admits a basis-like decomposition where reward appears only in downstream coefficient selection.
Theorem 2 (Zero-shot reward transfer, informal). Given a learned PSM basis with sufficient approximation quality, solving a downstream reward optimization over basis coefficients recovers the corresponding near-optimal occupancy (and policy) without further interaction data from the environment.
Theorem 3 (Approximation-to-control link, informal). If occupancy reconstruction error is bounded by $\varepsilon$ in the representation norm used by the method, then downstream value suboptimality is bounded proportionally to $\varepsilon$ and reward norm terms.

4. Optimization View

With basis matrix $\Phi=[\phi_1,\dots,\phi_K]$, downstream planning is recast as coefficient optimization:

$$\max_{w\in\mathbb{R}^{K}}\;\langle r, d_0 + \Phi w \rangle\quad\text{s.t.}\quad d_0 + \Phi w\in\mathcal{D}_{\text{feasible}},$$

where $\mathcal{D}_{\text{feasible}}$ encodes occupancy constraints (flow conservation, non-negativity, normalization). This separates representation learning (offline, reward-free) from task solving (fast coefficient solve).

Practical Learning Objective (template)

A generic training template is to fit basis components that reconstruct occupancies collected during reward-free exploration:

$$\min_{\theta}\;\mathbb{E}_{d\sim\mathcal{B}}\Big[\|d - d_{0,\theta} - \Phi_{\theta}\,\beta_{\theta}(d)\|_2^2\Big] + \lambda\,\mathcal{R}(\theta).$$

Here, $\beta_{\theta}(d)$ gives coefficients for each sampled occupancy object and $\mathcal{R}$ denotes regularization. Replace this with the exact objective/constraints implemented in your codebase.

5. Why This Works (Intuition)

  • Decoupling: environment dynamics are encoded once in basis functions; reward-specific adaptation happens only in coefficient space.
  • Linear reward structure: expected return is linear in occupancy, so linear combinations of basis occupancies naturally support fast reward re-targeting.
  • Coverage from reward-free data: broad exploration gives support over behavior modes needed for diverse downstream rewards.
  • Reusable computation: expensive interaction and representation learning are amortized across tasks.

8. Limitations and Open Directions

  • Behavior-space coverage can degrade in sparse-reachability regions without sufficient exploration.
  • Large or continuous spaces may require structured bases and scalable solvers.
  • Constraint handling in occupancy space can be numerically delicate in practice.
  • Future work: hierarchical proto-measures, uncertainty-aware basis selection, and online basis refinement.
